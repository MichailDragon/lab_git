**Выполнил:** Гущин Михаил, группа **БВТ2505**

Репозиторий содержит выполненные лабораторные работы по дисциплине **ВВИТ** (выполняются на языке **Python 3**), а также скриншоты результатов выполнения отдельных заданий.

## Содержание репозитория

| Папка | Тема работы | Краткое описание |
|-------|-------------|------------------|
| [`laba 1`](laba%201/) | Основы Python: ввод/вывод, типы данных, условия и циклы | Вывод нечётных чисел с помощью `for`/`while`, сравнение двух вещественных чисел (`if/else`, `max`) |
| [`laba 2`](laba%202/) | Функции | Функция приветствия, возведение в квадрат, максимум из двух чисел, функция с параметром по умолчанию (`describe_person`), проверка числа на простоту |
| [`laba 3`](laba%203/) | Работа с файлами | Чтение файла целиком и построчно, запись в файл (`w`) и добавление в файл (`a`), обработка исключений `FileNotFoundError` |
| [`laba 4`](laba%204/) | Модули и пакеты | Стандартные модули `math` и `datetime`, собственный модуль `my_module`, пакет `moduleee` с модулями `numbers` и `strings`, обработка `ValueError` |
| [`laba 5`](laba%205/) | ООП: классы и объекты | Класс `Book` (книга) с методом `get_info`, класс `Circle` (круг) с геттером и сеттером радиуса |
| [`laba 6`](laba%206/) | ООП: инкапсуляция и наследование | Класс `UserAccount` с приватным полем `__password` (смена и проверка пароля), наследование `Car` от `Vehicle` с переопределением метода |

| [`laba 8`](laba%208/) | Практическое задание (скриншоты) | Результаты выполнения работы №8 — файлы `lab 8_1.jpg`, `lab 8_2.jpg` |

Дополнительно в корне лежит [`new_file.txt`](new_file.txt) — учебный файл для отработки работы с Git (коммиты, ветвление).

## Требования

- **Python 3.8+** (код проверялся на Python 3.9)
- Сторонние библиотеки не используются — только стандартная библиотека (`math`, `datetime`).

## Как запустить

1. Клонируйте репозиторий:
   ```bash
   git clone <URL-адрес репозитория>
   cd <имя репозитория>
   ```
2. Перейдите в папку нужной лабораторной работы и запустите скрипт:
   ```bash
   python "laba 1/Lab1 ввит.py"
   python "laba 5/lab5-1.py"
   ```
   Некоторые программы запрашивают ввод с клавиатуры (числа, имена, пути к файлам) — следуйте подсказкам в консоли.

> **Примечание:** для файлов из `laba 3` (чтение/запись) запускать скрипты лучше из их папки, чтобы относительные пути к файлам (`example.txt`, `user_input.txt`) корректно разрешались; для `laba 4.2` и `laba 4.3` — из папки `laba 4`, чтобы Python нашёл модуль `my_module` и пакет `moduleee`.
